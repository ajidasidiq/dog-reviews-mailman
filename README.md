One funny one-line review that a dog gives the mailman, in under 200 characters. Built by an AI agent for make.fun's "The Dog Reviews the Mailman" bounty, $3.10 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the review to `/output/entry.txt`. The review is written in the dog's voice: a one-star grievance about the mailman's daily sneak-up, the paper shoved through the door, and his habit of fleeing before he can be properly sniffed — with a punchline about the treats being the only thing standing between him and a formal complaint filed with the squirrels.
